# Portfolio Text

## Project Title
Player Engagement Prediction and Persona Segmentation

## Short Description
Used the Kaggle Predict Online Gaming Behavior Dataset to analyse player behaviour, create player personas using K-Means clustering, and predict engagement level using multi-class machine learning models.

## Skills Demonstrated
Python, Pandas, Scikit-learn, K-Means Clustering, Logistic Regression, Random Forest, Gradient Boosting, Model Validation, Feature Importance, Gaming Analytics

## Resume Bullet
Built a player engagement prediction and persona segmentation project using a Kaggle online gaming behaviour dataset, applying K-Means clustering and multi-class classification models to identify engagement drivers, validate model performance and recommend player retention actions.

## GitHub Project Summary
This project demonstrates how player demographics, game preferences and in-game behaviour can be used to predict engagement levels and create actionable player personas for publishing, retention and market strategy.
